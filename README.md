# 🇪🇸 ESPAÑOL

## Personas. Datos. Sistemas.

No me gusta separar el trabajo con clientes del trabajo con datos, ni los datos de los sistemas que los convierten en decisiones.

Mi trayectoria ha seguido una evolución bastante natural:

```text
CUSTOMER
   ↓
UNDERSTAND
   ↓
DATA
   ↓
DECIDE
   ↓
AUTOMATE
   ↓
AI
   ↓
SYSTEM
   ↓
ADOPTION
```

Empecé trabajando directamente con personas y operaciones.

Después llegaron los datos.

Luego la automatización.

Después la IA.

Y finalmente la necesidad inevitable de construir sistemas que conecten todo lo anterior.

### Ese es el hilo conductor de mi trabajo:

> **Entender el problema → convertirlo en criterio → construir el sistema → conseguir que se use.**
