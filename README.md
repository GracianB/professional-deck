## Why this portfolio exists

This repository is a public professional narrative built around real operational context and evidence, not a generic CV template.

- It shows how customer operations, service quality, data, automation and decision systems connect in practice.
- It presents selected public proof instead of hiding the story behind long lists of responsibilities.
- It leads to the canonical application materials hosted in the main hub repository, keeping the source of truth clear.

> The deck is evidence-first: how work actually moved, what decisions were made, and what systems were built to improve them.

---

## The signal in one minute

`client → operations → data → decisions → systems → adoption → outcome`

This is the trajectory behind the portfolio:

- Support operations and customer experience
- Service workflows, reporting and information quality
- Automation, data structure and decision support
- Systems thinking applied to growth and operational resilience

The result is a story that connects daily work to measurable outcomes, without pretending every demo is a production system.

## Career narrative

This portfolio combines:

- customer-facing work and service operations
- process, reporting and support systems
- operational data and decision support
- automation and AI-assisted tooling
- cross-functional communication in changing environments

The reading experience is deliberately designed to support two modes:

1. Quick scan: public proof, relevant projects and how the work connects.
2. Deeper read: operational model, case context, geography, experience and decision-making.

The city atlas and chapter structure are narrative context, not deductions from a map of job titles.

## Quality and validation

This repo includes checks for structure, local references, CSS guards, browser behavior and production routes.

```bash
npm ci
npm run validate
npm run verify
```

The full `npm run quality` gate includes browser and cross-browser verification, CSS audits and production smoke tests. It validates the state of the repository at that revision and does not claim business outcomes or guarantee external third-party demos remain available forever.
